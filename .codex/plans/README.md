# ExecPlan 索引

`.codex/plans/` 保存一次性任务的执行过程，不是当前产品状态的权威来源。

- 当前产品与工程状态：看根目录 [PLAN.md](../../PLAN.md) 和 [开发状态与分支进度](../../docs/development_status.md)。
- 已完成任务：保留原计划、分支、提交和验证结论，用于历史追溯，不自动代表当前主线。
- 当前任务：[`docs-ios-alignment.md`](docs-ios-alignment.md)。
- Web 相关计划：属于已冻结 Web 验证阶段，不作为 iOS v2 功能依据。

## 维护规则

新任务完成后，在对应计划中记录实际分支、提交、验证结果和未验证项；不要用旧计划替代当前看板，也不要把未合并分支的能力写成主线能力。
