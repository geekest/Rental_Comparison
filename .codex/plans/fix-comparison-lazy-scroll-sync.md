# 修复详细数据延迟加载后的横向同步

## 1. 任务目标

修复对比页“详细数据”中，用户先横向滑动一个分组、再纵向浏览到后续分组时，后续分组未继承当前横向位置的问题。完成后，真实成本、通勤时间、条件风险、看房记录与置顶房源表头应始终展示同一列。

## 2. 当前状态

- `Rental_Comparison/ComparisonView.swift` 为置顶表头和 4 个 `ComparisonSection` 分别创建横向 `ScrollView`。
- 旧实现为表头和每个 `ComparisonSection` 分别创建横向 `ScrollView`，再以 UIKit KVO 复制 `contentOffset`。
- 新增的 3 房源 UI 测试可以在模拟器中验证 KVO 同步，但用户在真实使用中仍复现详细数据不同步，说明该跨层级桥接方案不可靠。
- 现有 UI 测试仅覆盖已提前显示的成本、通勤与表头，未覆盖全部详细数据分组。

## 3. 目标状态

- 表头和所有详细数据分组由同一个横向 `ScrollView` 承载，天然保持同列对齐。
- 纵向滚动时，表头继续置顶；横向滑动时，表头和全部详细数据一起移动。
- UI 回归测试覆盖“横向滑动后再纵向进入后续分组”的路径。

## 4. 范围边界

### 本次包括

- 用单一横向滚动轨道替代各分组之间的偏移复制。
- 为详细数据列补充可定位的测试标识与回归测试。
- 运行 iOS 构建和相关 UI 测试。

### 本次不包括

- 调整对比页业务字段、数据模型或最终选择流程。
- 修改 Web MVP。

## 5. 影响文件

- `Rental_Comparison/ComparisonView.swift`：由单一横向容器承载置顶表头与详细数据列。
- `Rental_ComparisonUITests/RentalComparisonUITests.swift`：覆盖延迟出现分组的同步行为。

## 6. 执行里程碑

### Milestone 1：建立延迟加载回归路径

要做：为每个详细数据列提供稳定的测试定位，并新增“成本横滑后进入条件风险/看房记录”的 UI 测试。

验证：修复前测试在后续分组的横向位置断言失败。

完成标准：测试捕获用户描述的不同步现象。

### Milestone 2：改为统一横向轨道

验证：3 房源测试验证横滑后，成本、通勤、条件风险、看房记录的列位移相同。

完成标准：所有详细数据分组与表头显示同一列。

## 8. 新发现与意外情况

- 发现：上一版测试只验证成本、通勤和置顶表头，无法覆盖条件风险与看房记录。
- 影响：即使扩展后的 3 房源测试可通过，用户仍在手动路径复现问题；KVO 同步依赖 SwiftUI 内部 `UIScrollView` 层级，不应作为可观察行为的唯一保证。
- 处理方式：删除 KVO 桥接，改由一个物理横向容器承载所有比较列。

## 9. 决策记录

### Decision：使用单一横向滚动容器

选择：在外层建立一个横向 `ScrollView`，内部保留垂直 `ScrollView`；置顶表头和详细数据作为同一横向内容的一部分。

原因：表头与所有详细数据共用同一个原生滚动位置，不再依赖延迟创建、KVO 和 UIKit 视图层级探测。

备选方案：保留多个横向容器并继续补强偏移恢复。

影响：横滑同样会作用于对比页当前内容宽度；不涉及业务数据或存储。

## 10. 验证计划

- `xcodebuild ... -only-testing:Rental_ComparisonUITests/...`：验证成本横滑后延迟出现的条件风险、看房记录与表头同列。
- `xcodebuild ... build`：验证 iOS 编译。
- `git diff --check`：验证补丁格式。
- Simulator 手动路径：打开对比页，展开详细数据，横滑真实成本，纵向进入通勤、条件风险与看房记录，确认每组显示相同房源列。

## 11. 风险与回滚

- 风险：嵌套横向和纵向滚动容器的手势优先级需由 UI 回归测试验证。
- 缓解：仅保留一个横向手势识别位置，并覆盖 3 房源下的全分组列位移。
- 回滚：撤销本次 `ComparisonView.swift` 和 UI 测试的提交即可恢复当前行为；不涉及数据迁移或持久化。

## 12. 最终结果与复盘

完成于 2026-08-25。

- 置顶房源表头、详细数据 4 个分组现在共同位于一个横向 `ScrollView`；垂直 `ScrollView` 继续负责页面浏览和表头置顶。
- 删除依赖 SwiftUI 内部 UIKit 层级的 KVO 协调器，避免延迟创建分组时出现不同步。
- 新增 3 房源 UI 回归测试，拖动真实成本后验证成本、通勤、条件风险、看房记录的列位移一致。
- 验证通过：iOS Simulator 构建；新增的全分组同步测试；详细数据折叠/展开；置顶表头纵向滚动。
