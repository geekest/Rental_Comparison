## 9. 决策记录

### Decision：需求与实现状态分开记录

选择：保留 MVP 与核心规格的目标行为，新增“当前 Web 实现状态”与“剩余差距”。

原因：直接修改需求以匹配代码会掩盖未完成工作，也会破坏已确认产品共识。

备选方案：把所有验收项标记完成；因存在字段、通勤和比较分组缺口而不采用。

影响：下一轮任务可以直接从差距清单拆分，不需要重新审计。
