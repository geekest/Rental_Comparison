# 修复详细数据分组的局部横向同步

## 1. 任务目标

修复对比页“详细数据”中，横滑某个二级分组后，其余二级分组的数据列未保持同一横向位置的问题。

完成后，真实成本、通勤时间、条件风险和看房记录的 **数据内容** 互相同步；页面本身、置顶房源表头、"详细数据"／"对比分析" 标题、二级标题和对比分析内容不随该手势横向移动。

## 2. 当前状态

- 当前 `dd1c314` 将整个页面的 `LazyVStack` 放入外层横向 `ScrollView`，使页面级标题、分析区和操作按钮都可横滑，超出需求范围。
- 初始结构（`5b46b19^`）保持页面纵向 `ScrollView`，并让 `ComparisonHeader` 和各 `ComparisonSection` 的数据行各自横滑；该边界符合本次要求。
- 初始协调器只能同步已注册的 `UIScrollView`。二级分组在后续出现或重新创建时，没有可靠地继承当前横向偏移。
- 现有 `testComparisonDetailsKeepAllSectionsOnTheSameColumn` 在当前外层横向结构下会通过，不能证明局部滚动边界正确，必须替换。

## 3. 目标状态

- 外层页面只允许纵向滚动。
- 每个 `ComparisonSection` 保留独立横向数据区域；“详细数据”标题、二级标题和说明文字留在该横向区域外。
- 协调器保存最后一次有效横向偏移，并在二级数据区域后续注册、重新显示时应用该偏移。
- 对比分析区域不加入横向同步。

## 4. 范围边界

### 本次包括

- 撤销 `dd1c314` 引入的页面级横向容器。
- 恢复局部数据区域的横向容器与同步协调器，并补强后注册区域的偏移继承。
- 将 UI 回归测试改为验证局部范围：横滑数据后，二级标题和对比分析标题的 X 坐标不变，所有数据列保持相同位移。

### 本次不包括

- 修改房源、费用、通勤或分析业务逻辑。
- 改变对比分析卡片的布局或让其横向同步。
- 调整置顶房源表头的横向交互。

## 5. 影响文件

- `Rental_Comparison/ComparisonView.swift`：恢复局部横向滚动边界，补强协调器。
- `Rental_Comparison/AppStore.swift`：保留或调整 3 房源 UI 测试 fixture。
- `Rental_ComparisonUITests/RentalComparisonUITests.swift`：替换页面级同步断言。
- `.codex/plans/fix-comparison-section-only-sync.md`：记录实施与结果。

验证：在恢复初始局部容器、但未补强后注册偏移前，测试应能捕获不同步或重新显示后的偏移丢失。

验证：Milestone 1 测试通过，页面标题 X 坐标保持不变。

完成标准：无页面级横滑回归，补丁格式正确。

## 8. 新发现与意外情况

- 发现：上一提交的测试只验证所有元素位移相等，未断言页面标题和分析区保持固定，因此验证了错误的交互范围。
- 处理方式：新测试将同步数据列与固定标题分别断言。
- 发现：当前页面级实现的回归测试稳定失败，横滑后“详细数据”标题从 `x = 24` 移到 `x = -206`。
- 处理方式：恢复页面纵向容器；协调器仅注册每个 `ComparisonSection` 的横向数据区域，并在新区域布局完成后恢复保存的偏移。

## 9. 决策记录

### Decision：保留页面纵向、数据分组横向的嵌套边界

选择：只在 `ComparisonSection` 的数据列区域处理横向同步。

原因：这符合用户最终确认的范围，并保持“详细数据”“对比分析”以及二级标题的正常页面布局。

备选方案：单一页面级横向滚动容器。

不选原因：会让无关标题、分析区和操作区横滑，已被用户明确否定。

## 10. 验证计划

- 定向 UI 测试：局部数据列同步且标题固定。
- 定向 UI 测试：详细数据、对比分析折叠/展开；置顶表头纵向滚动。
- `xcodebuild ... build`：iPhone 16e Simulator 编译。
- `git diff --check`：补丁格式。
- 手动路径：横滑“真实成本”数据，向下查看通勤、条件风险、看房记录；确认数据列同列，而各级标题和对比分析没有横移。

## 11. 风险与回滚

- 风险：UIKit 层级解析过早可能注册到外层纵向滚动视图，或新建数据行错过当前偏移。
- 缓解：只注册具有实际横向可滚动范围的最近祖先，并在其内容尺寸可用后恢复偏移；用标题固定断言防止范围回归。
- 回滚：可对 `dd1c314` 执行 revert，恢复到之前已推送的 `5b46b19`，不涉及数据迁移。

## 12. 最终结果与复盘

已恢复页面纵向容器，并只让“详细数据”四个二级分组的数据区域共享横向偏移。置顶房源表头保留原有独立横滑能力，但不会被数据区手势带动；页面标题、二级标题、对比分析和操作区均不会横移。

验证结果：

- 新回归测试在页面级横滑实现下稳定失败：横滑后“详细数据”从 `x = 24` 移到 `x = -206`；恢复局部结构后通过。
- `testComparisonDetailsSynchronizeDataWithoutMovingPageTitles` 通过，覆盖四个数据分组同步、标题固定和折叠后偏移继承。
- `testComparisonSectionsSynchronizeWithoutMovingHeader`、详细数据／对比分析折叠展开、置顶表头纵向可见性测试均通过。
- iPhone 16e Simulator 的 `xcodebuild build` 通过，`git diff --check` 通过。
